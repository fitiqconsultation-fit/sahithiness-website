# Sahithiness – Nutrition + Movement for Women

Landing page for Sahithi's prenatal, postnatal and at-home fitness and nutrition programs.

## Files
- `index.html` – the whole page (text, styles, enrollment form, consultation calendar)
- `images/` – compressed photos (`.webp`)
- `.htaccess` – compression, caching and https redirect for Hostinger

## Common edits (in `index.html`)
- Programs and prices: search for `var PACKAGES`
- WhatsApp number: search for `wa.me/`
- Sample class video: search for `var SAMPLE_VIDEO` and paste a YouTube link

## Hosting
Deployed to Hostinger from the `main` branch into `public_html`
(hPanel → Websites → Manage → Advanced → GIT).
